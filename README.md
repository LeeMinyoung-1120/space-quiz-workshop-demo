# 오비트 · 우주 탐사 퀴즈

외부 의존성 없이 `index.html` 하나로 실행되는 한국어 우주 탐사 퀴즈입니다.

## 실행

`index.html`을 브라우저에서 엽니다. 서버, 패키지 설치, 인터넷 연결은 필요하지 않습니다.

## 기능

- 10개의 객관식 문항과 해설, 문항당 10점의 점수 카운터
- 답변 완료 수를 보여 주는 진행률 표시줄
- 녹색 정답 애니메이션과 빨간색 오답 흔들림
- 점수별 이모지 결과 화면과 다시 시작
- 키보드 탐색, 스크린 리더용 상태 안내, 반응형 화면
- 시스템 라이트/다크 모드 및 모션 감소 설정 지원

## 키보드 조작

`Tab` / `Shift+Tab`으로 이동하고, 방향키로 보기를 선택합니다.
`Space`로 선택하거나 버튼을 누를 수 있으며, `Enter`로 답을 확인하고 다음 문항으로 진행합니다.

## 실습 파일

| 파일 | 용도 |
|---|---|
| `index.html` | HTML, CSS, JavaScript를 모두 포함한 퀴즈 |
| `AGENTS.md` | 프로젝트 수정 지침 |
| `.gitignore` | 비밀 정보와 로컬 산출물 제외 |
| `README.md` | 실행 방법과 실습 안내 |

## 변경 후 확인

10문항을 끝까지 진행해 점수, 진행률, 정답·오답 해설, 결과 화면을 확인합니다.
다시 시작하면 점수와 진행률이 초기화되어야 합니다.
키보드만으로 전체 흐름을 진행하고, 시스템 테마와 모션 감소 설정,
좁은 모바일 화면에서도 확인합니다.

커밋 전 `git diff --cached`로 게시할 내용을 확인합니다.
토큰, 비밀번호, 개인 파일, 로컬 설정은 저장소에 추가하지 않습니다.
