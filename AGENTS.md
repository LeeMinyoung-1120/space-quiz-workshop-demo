# Project instructions

- Keep the application in `index.html`, including all HTML, CSS, and JavaScript.
- Do not introduce servers, build steps, packages, CDNs, remote fonts, or network requests.
- Keep the user interface and quiz explanations in Korean.
- Preserve 10 questions, four choices per question, and 10 points per correct answer.
- Preserve progress tracking, answer explanations, result reactions, and restart behavior.
- Use semantic HTML and native controls. Preserve keyboard navigation, visible focus,
  screen reader announcements, and focus management between questions and results.
- Do not communicate correctness through color alone.
- Respect `prefers-color-scheme`, `prefers-reduced-motion`, and forced colors.
- Keep the layout usable on narrow mobile screens.
- After behavior changes, open the file locally and exercise correct and incorrect answers,
  all 10 questions, scoring, results, restart, and the full keyboard-only flow.
- Update `README.md` when usage changes.
- Review staged files before committing. Never commit credentials, personal files,
  browser profiles, environment files, or unrelated generated artifacts.
